First public release of KSA VC Quick ID Inspector.

- Inspect a pedestrian's model ID and health while aiming.
- View the current vehicle's name, model ID, and health.
- Type `KSAID` to toggle the pastel overlay.
- Includes crosshair detection for Classic Axis mouse aiming.

### Installation

Download `KSA_VC_Quick_ID_Inspector_v1_0_0.zip`, extract it, and copy the script from its `CLEO` folder into your game's `CLEO` folder. Install only one copy. GitHub's source-code archives are for development, not ready-to-use installation.

Requires the original Windows version of **GTA: Vice City 1.0** and **VC.CLEO 2.2.0**. Not for San Andreas or the Definitive Edition. Dependencies are not bundled.

Gameplay testing by KSAGlory confirmed startup instructions, toggling, vehicle information, and pedestrian information with Classic Axis mouse aiming. Controller lock-on, mouse aiming without Classic Axis, obstacle edge cases, and extended gameplay remain unverified.
