KSA VC Quick ID Inspector
Version 1.0.0
Author: KSAGlory

A lightweight in-game pedestrian and vehicle model inspector for GTA: Vice City.

REQUIREMENTS
Original GTA: Vice City 1.0 for Windows and VC.CLEO 2.2.0.
CLEO: https://github.com/cleolibrary/III.VC.CLEO
Not compatible with San Andreas or the Definitive Edition.

INSTALLATION
Close the game. Copy KSA_VC_Quick_ID_Inspector.cs from this archive's CLEO
folder into your game's CLEO folder. Install only one copy, then restart.
No other mods or game files are included in this download.

HOW TO USE
The inspector starts enabled. Type KSAID during gameplay to toggle it.
Aim a weapon at a pedestrian to display their model ID and health.
Enter a vehicle to display its name, model ID, and health.
Replacement models retain the original game IDs and vehicle names.

UNINSTALLATION
Close the game and remove only KSA_VC_Quick_ID_Inspector.cs from CLEO.
Do not delete or change your saved games.

TESTING
KSAGlory confirmed startup, toggling, vehicle information, and pedestrian
information with Classic Axis mouse aiming on Windows 11, Vice City 1.0,
and VC.CLEO 2.2.0. Controller lock-on, mouse aiming without Classic Axis,
obstacle edge cases, and extended gameplay have not been verified.
