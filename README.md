# KSA VC Quick ID Inspector

A CLEO model inspector project for Grand Theft Auto: Vice City, based on [KSA Quick ID Inspector](https://github.com/KSAGlory/KSA-Quick-ID-Inspector) for San Andreas.

The inspector is designed for players, mod testers, and creators who need to identify pedestrian and vehicle models directly in the game. The Vice City adaptation is being prepared.

## Planned features

- Show a targeted pedestrian's model ID and health
- Display the current vehicle's name, model ID, and health
- Toggle the inspector with the `KSAID` cheat code
- Keep the compact pastel interface used in the San Andreas version

## Development

The port targets the classic Windows version of Grand Theft Auto: Vice City. Supported executable and CLEO versions will be documented after compatibility testing.

Source code and setup instructions will be added as the adaptation progresses.
